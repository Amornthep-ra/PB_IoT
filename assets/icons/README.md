# Icon Assets

Organize icons by screen or feature so they are easy to find and reuse.

Suggested usage:
- `assets/icons/dashboard_builder/` for Dashboard Builder page icons and artwork
- `assets/icons/dashboard/` for Dashboard page icons
- `assets/icons/notifications/` for Notifications feature icons
- `assets/icons/account_session/` for Account Session page icons
- `assets/icons/forgot_token/` for Forgot Token page icons
- `assets/icons/profile/` for Profile page icons
- `assets/icons/request_token/` for Request Token page icons
- `assets/icons/token_login/` for Token Login page icons
- `assets/icons/shared/` for icons reused across multiple pages

Example asset path:
`assets/icons/dashboard_builder/empty_state_greenhouse.png`
